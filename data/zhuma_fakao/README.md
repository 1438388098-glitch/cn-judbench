> **边界声明（先读）**：本目录是**扩展候选池**，不是 CN-JudBench 公开题库的一部分。
> 公开题库 = `data/public/` 12 包 323 题（MANIFEST 对账）。本目录 4139 题**不入
> MANIFEST、不参与判分、不进任何跑分与论文表**；`src/`、`tests/`、`scripts/`、
> `tasks/`、`configs/` 对本目录**零消费**（仅只读人工取材）。

## 来源与抓取

- 来源：竹马法考（zhumavip）题库，`pcSelectByCatalogId` 接口按卷整取（含答案字段）。
- 抓取日期：2026-09-24（commit 59504f3）；2011–2025 历年真题客观题共 37 卷 4139 题。
- 文件：按卷 JSON（`YYYY_卷N.json` / `YYYY_客观N.json`）+ 汇总
  `all_objective_questions.json`；字段统一 `question / options / answer / type / year / id`，另含 `source`。
- 用途：只作为后续扩题（draft → 双隔离考生 → gold 裁定 → 入库全流程）的**素材池**；
  入库题必须改写为合成题面并走 docs/examinee-round-pack.md 全流程，禁止原文照搬。

## 与公开题库的隔离证据

- 2026-09-24 审计机检：323 题公开题库与本池题干**精确匹配零重叠**。
