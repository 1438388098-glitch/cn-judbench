# u_element_extract · 参考解与金样构造规则

## 金样结构

`gold` 为答案对象：`{"amount": <数字>, "date": "YYYY-MM-DD", "case_no": "..."}`。

- `amount`：涉案金额，纯数字（元）；`on_fail: partial` 按命中进题分基数。
- `date`：案情中唯一的关键日期（约定的还款/履行/作案日），ISO 格式。
- `case_no`：输入原样给出的案号，**既是 FTP 值也是 PTP 保持对象**
  （`field_keep` → 篡改已知事实 cap_50）。

## 判分语义（P0b 执行器）

- mock:gold 满分 = 三要素全对 + 案号原样；
- 篡改案号 → cap_50；金额/日期错 → 基数按命中均值折减；
- 答案不可解析 JSON → 0.00（format_fail）。

## 构造纪律

1. 每题案情必须包含全部三要素，日期有且仅有一个关键日。
2. `law_anchors` 填真实相关条文（民法典/刑法常用条，见 lawkb）。
3. 金额用阿拉伯数字，避免「十万」类中文数字（P0b 不做数字词转换）。
