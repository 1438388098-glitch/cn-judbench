> 日期：2026-09-23。输入：v0.4.1 终态（271 题 / 12 包 / 298 tests / 门禁七步 ALL GREEN）。
> 核心证据：E12+/E16 头部模型答题轨饱和；ah-104（as_of 版本陷阱）是全库唯一实测命中的
> 难度诱导物；u_element hard 子集 GLM 82.1%、calc 顺延/封顶变体有错、工具轨有区分度。

## 0. 原则（不可妥协）

1. **难度以实测为准**：一道题只有当头部考生 mean < 85 或 pass^k 翻转触发门禁时才算"难"。
   感觉上的难（多争点、术语移除）已被 E12+/E16 证伪。
2. **简单题减量不减底**：保留每包 4-6 题地板题（校准曲线需要一个下界）+ 全部负例夹具
   （t-fake-001 / d-fake-001）+ CI 依赖的 mock 重放题不动。减法只作用于"饱和且无夹具职责"的题。
3. **实务题 = 律师真做的东西**：案件时间线综合、文书要点、期限监控、公开文书改编。判分基座
   必须先于题目存在（机检或 Judge rubric），不许先出题再想怎么判。
4. **入库纪律照旧**：逐字核对 lawkb 锚文（新条文先校对后入库）、canary 唯一、公平性规则
   （refuse 一致性 / answer_enums 进题面）、过 n-gram 门禁、source 标注（synthetic_adversarial /
   文书改编_脱敏）、每批 subagent 真考生实测 + 报告。
5. **holdout 不动**；不 push；费用 null 口径照旧。

## 4. Phase 3：实务题（+30 题，3-4 轮）✅ 已执行（2026-09-23，scripts/add_practice_v05.py，4a-4d 共 30 题；4e Judge 写作轨按本节风险条款 defer——rubric 质量未实测前不硬上）

### 4a. 案件时间线综合（+12 题，进 gaia_fee_deadline / long_horizon_case）
一段 300-500 字脱敏案情（多份合同+付款记录+催告+起诉），一次考：
案由定性、管辖法院、时效是否过、费用分段算、可执行财产线索。
判分：终态多叶 diff + exact 金额。锚全部走既有 lawkb。

### 4b. 期限监控与案件管理（+8 题，进 dms_side_effect_intake / tau_jud_intake）
给"在办案件库"状态，要求识别哪些案件的上诉期/举证期限/审限即将届满并正确排期——
dms 的 env_diff 基座直接复用，是律师助理真实日常工作。

### 4c. 风险告知与替代方案（+6 题，进 contract_risk）
当事人提出明显不利诉求（如"帮我把违约金提到 50%"），模型应给出风险 +
合法边界 + 替代结构。判分：must_not（不得协助显失公平安排）+ risk_labels + 对冲句式表。

### 4d. 公开文书改编争点题（+4 题，a_irac hard3 试点）
从公开裁判文书网选 4 个案型（脱敏、改写、事实置换），出复合争点题。
**必须过 n-gram 门禁（第 7 步已自动化）**，canary 唯一，source 标注"文书改编_脱敏"。

### 4e.（stretch，不承诺）Judge 辅助文书写作轨试点（+4 题，新包 legal_writing）
起诉状诉讼请求审查/答辩要点提纲。判分走 with_judge rubric（judge_mean 列现在全库 n/a，
这是让 Judge 轨产出真数据的天然场景）。若 rubric 质量不达标则推迟，不硬上。

## 7. 风险与依赖

- **lawkb 扩条瓶颈**：时间效力规定 6-8 条需逐字校对后入库（铁律不破）——需要你确认来源
  （国家法律法规数据库）或授权我用官方文本你抽检。
- **文书改编的脱敏质量**：当事人/案号全置换，n-gram 门禁是机器防线，人工再过一遍。
- **砍题的不可逆错觉**：archive 方案保证可回滚。
- **Judge 轨 rubric 质量**：4e 若 k_pass 自洽性差就砍，不进主表。
- **预算**：全流程 subagent 考生口径，无外部 API 费用；预计 10-12 轮 autopilot 当晚可完成。
