# calc_fail_to_pass 隐藏单测 oracle 实测（R4，2026-09-23）

被测：GLM-5.3-Flash（subagent 考生，单样本）· 抽样：三族各取代表共 12 题（首轮）/ 10 题复测
打分：正式管线回灌（runs/calc-glm1/scored，manifest 46dac42314fa）

## 结论

1. **oracle 公平性修复**：初版 prompt_template 未告知规范 formula_id，GLM 三族数值
   12/12 全对、却 11/12 因自由文本标识被记半分（mean 62.5）——这是判分缺陷不是模型缺陷。
   修复：题面枚举 `fee_tiered_2007` / `simple_interest_365` / `period_days` 三标识。
   教训进 reference.md：**规范标识必须在题面枚举**，任何隐藏约定都属不公平判分。
2. 修复后复测 10 题：**9 题满分（mean 95.00）**，cf-017（标的额 200 万受理费）数值
   从首轮的 22800（对）翻成 18800（错）——**同题两次作答翻转**，是 pass^k 组合语义
   进主表（§6.2）的直接实证；单样本分数须带 k≥3 复跑才能进对比表。
3. 三族对 GLM 的区分力现状：受理费/单利利息/简单期间均为「公式可解」题，
   rules 基线≈满分、GLM≈95+，**区分对象应是中等模型与长输入变体**
   （后续批次：复合利息、LPR 上限裁剪、跨期对月计算、节假日顺延）。
