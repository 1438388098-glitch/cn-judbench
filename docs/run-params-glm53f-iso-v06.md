## 1. 组织方式（用户指定：8 个 subagent 每包一个）

1. `export_prompts.py` 按包导出 8 个隔离目录（prompts/answers/index/EXAMINEE.md）；
2. 并行派发 8 个 subagent 考生，系统提示词只含：读题目录、写答目录、落盘协议
   （JSON 全文即文件全文）、禁止读其他文件/联网/执行命令；
3. 换答 guard：245 题文件数核对 + JSON 逐个可解析（两轮补漏后全过）；
4. 合并 answers → `file:` 回灌统一判分。

**实际 agent 数**：主跑 8 + 速率限制重试 2 + 漏题补答 2 + calc hard 补答 1 = **11 次**调度

且含一个 cd-001 笔误文件已剔除）。

## 3. 三个测量结论

1. **自答污染量被校准**：同模型同题集，自答 69.36 vs 隔离 59.14——**接触 gold/判分器
   的乐观偏差 ≈ 10 分**。自答跑仅作管线验证的定位得到实证支持。
2. **T2 跨模型区分度成立（首个双模型隔离对照）**：DS-flash 68.72 vs GLM 隔离 59.14，
   差距近 10 分，来源集中且可解释——a_irac（75.22 vs 47.79，长文推理）与
   gaia（86.96 vs 60.87，费用/期间精确计算）；GLM 仅在 contract 小幅领先。
   答题轨内部分化清晰，不再是单模型孤证。
3. **s_charge 判分面对所有考生极苛**：隔离考生 11.96 为全库最低——罪名判定正确但
   elements 措辞与金样短语 set_f1 失配（DS 29.08、自答 25.36 同型），该包的
   判分面（要素短语表是否应开放同义口径/进题面）建议列入考生轮复核清单。
