# 调研摘要（Subagent 三路汇合）

> 用途：框架设计的证据底座。标【实读】= 本次抓取到 README/论文摘要；【检索】= 仅搜索摘要；【推断】= 归纳或记忆。

## 1. 现有中文司法/法律 Benchmark

| 项目 | 核心设计 | 对本框架的启发 |
|---|---|---|
| **LawBench** (open-compass)【实读】 | 记忆/理解/应用三层 × 20 任务，10k 题；Acc/F1/ROUGE-L/刑期 log-distance/弃权率 | **首选可复用壳**：任务元数据、多指标、弃权率 |
| **LexEval**【实读】 | LexCog 六能力（含伦理）× 23 任务，14k+ 题 | 能力分类学；伦理维度 |
| **JEC-QA** (THUNLP)【实读】 | 法考客观题，知识 + 案例分析 | 知识维源头题库 |
| **CAIL2018**【实读】 | 罪名 / 法条 / 刑期三联 | 司法预测任务金标准 |
| **DISC-Law-Eval**【实读】 | 客观选择 + 主观问答；GPT 按准确/完整/清晰 1–5 分 | 主观三维 LLM 评分 |
| **MSLR-Bench**【实读】 | 内幕交易：schema 抽取 + IRAC 说理；字段精确评 + LLM 等级 | 要素与说理解耦 |
| **LeCaRD / v2**【实读/检索】 | 类案检索 NDCG；v2 三维相关（定性/量刑/程序） | 检索独立成轨 |
| **Lawyer LLaMA 评测**【实读】 | 咨询质量 GPT-4 0–10 分，对照律师金标准 | 金标准对照评分细则 |
| **LegalBench**（英）【实读】 | 162 小任务模块化众包 | **任务包协议**直接借鉴 |
| **LegalBench-RAG**【检索】 | 法律 RAG 可答性 | RAG 管道评测 |

**明确空白**：中文合同审查、跨案由裁判说理、法条引用幻觉校验、多轮角色对话、可复现 judge、法条时效治理。

## 2. 评测框架架构经验

| 框架 | 可抄点 | 局限 |
|---|---|---|
| lm-eval-harness【实读】 | YAML 任务、output_type 四型、filter 管道、GroupConfig micro/macro、decontamination、plugins | 主观长文弱 |
| OpenCompass【实读】 | 中文生态、CascadeEvaluator（规则优先）、国产 API 适配 | 配置重 |
| HELM【实读摘要】 | 场景 × 7 指标矩阵 | 工程重 |
| BIG-bench【实读】 | keywords 受控标签、canary 防污染 | 已归档 |
| MT-Bench / Arena【实读摘要】 | LLM-judge 可规模化；位置/冗长/自我偏好三类偏差 | Elo 只适合相对排序 |
| GAIA【实读摘要】 | 公开部分题 + 扣留答案 | — |

**流水线共识**：`数据层 → 任务层 → 适配层 → 指标层 → 报告层`  
**默认策略**：规则指标优先，Cascade 到 LLM-judge；人评 5–15% 校准。

## 3. 司法能力维度候选（8 维，经调研归纳）

1. 法律知识记忆  
2. 文书理解与要素抽取  
3. 规范识别与法条检索  
4. 事实—规范涵摄（三段论）  
5. 争点分析与案例论证  
6. 结果与量刑预测  
7. 文书生成与说理  
8. 角色化服务与风险沟通  

**横切风险轴（调研空白 → 本框架必须内建）**：引用真实性/时效、拒答与执业边界、幻觉法条、地方/审级一致性。

**数据可得性**：JEC-QA、CJRC、LEVEN、CAIL 系列、STARD、LeCaRD、DISC-Law-SFT、JuDGE、FLK 法条库；合同审查与行政/执行需自建。
